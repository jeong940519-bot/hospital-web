왼쪽에서 글을 선택하거나 새 글을 작성하세요
AI가 병원 정보를 반영해 네이버 블로그 초안을 만들어 줍니다.
네이버는 공식 자동 발행 API를 제공하지 않습니다. (2020년 5월 '글쓰기 API' 종료)
여기서 초안을 완성한 뒤 「스마트에디터용 복사」 → 네이버 블로그 글쓰기 창에 Ctrl+V 로 붙여넣어 발행하세요. 서식(소제목·목록·인용)이 그대로 옮겨집니다.

1️⃣ 글감 설정

선택된 템플릿 없음 — 「📋 템플릿 넣기」로 글의 뼈대를 고르면 AI가 그 구성대로 씁니다.
키워드만 넣고 「✨ AI로 초안 생성」을 눌러도 됩니다 — 글감 후보를 먼저 보여드립니다.
제목·첫 문단·소제목에 자연스럽게 배치됩니다.

2️⃣ 제목

네이버 검색 노출에는 공백 포함 25~35자가 무난합니다. 현재 0자

3️⃣ 본문

공백 포함 0자 공백 제외 0자 주 키워드 0회 소제목 0개 이미지 자리 0개 넣은 사진 0장

4️⃣ 해시태그

네이버는 글당 최대 30개까지 등록됩니다.

5️⃣ 의료광고법 검수

검수 기준: 전문(국가법령정보센터)을 AI에게 그대로 제공해 판정합니다. 다만 이는 보조 검사이며 최종 책임은 게시 주체에 있습니다. 사전심의 대상 매체에 게재할 때는 별도 심의 절차를 확인하세요.

6️⃣ 네이버에 올리기

1네이버 블로그 글쓰기 창을 엽니다새 탭에서 열립니다
2제목을 복사해 붙여넣습니다제목 칸에 Ctrl+V
3본문을 복사해 붙여넣습니다본문 칸에 Ctrl+V — 소제목·목록 서식이 함께 옮겨집니다
4사진을 저장해 순서대로 올립니다본문에 넣은 사진이 없습니다
5태그를 복사해 붙여넣습니다글 맨 아래 태그 칸에 Ctrl+V

7️⃣ 발행 기록

붙여넣기로 발행한 뒤, 글 주소를 여기에 저장해 두면 목록에서 발행 여부를 한눈에 볼 수 있습니다.

⚙ 새 글 기본값

1️⃣ 글감 설정 체크한 항목만 새 글에 미리 채워집니다 · 체크를 끄면 평소처럼 비워 둡니다
🖼 글 맨 아래 기본 사진 올려두면 모든 글의 끝에 항상 들어갑니다 (오시는 길·진료 안내 이미지 등)
📋 사진을 여기서 Ctrl+V 하거나 끌어다 놓기 ·
순서대로 본문 맨 아래에 붙습니다. 사진 아래 설명은 「사진 설명 포함」 옵션을 켰을 때만 복사됩니다. 저장은 즉시 됩니다.
🚫 금지어 제목·본문·태그·키워드에 절대 넣지 않을 단어 (쉼표 구분)
AI에게 규칙으로 전달하고, 그래도 들어오면 제목 후보·태그·키워드에서 자동으로 뺍니다.
🤖 AI 모델 역할별로 고릅니다 · Opus는 Sonnet의 약 5배 비용
권장(기본): 글감 추천 Opus 5 · 초안 Sonnet 5 · 제목 다시 뽑기 Opus 5(둘 다 출력 짧아 저렴) · 검수 Opus 5 · 보조 Haiku 4.5 · 형식 가져오기 Sonnet 5. 문장 품질을 특별히 끌어올릴 글만 초안을 Opus 5로 바꿔 생성하세요.
🔤 글꼴 에디터 표시와 네이버 붙여넣기에 함께 적용
네이버가 글꼴을 못 알아보면 기본 글꼴로 붙습니다 — 그때는 네이버 에디터에서 Ctrl+A 후 글꼴만 한 번 바꾸면 됩니다.

📸 사진 세트 — 컨셉별로 모아두면 AI가 자리마다 골라 넣습니다

🔖 네이버 태그칸 자동 입력

네이버 태그칸은 한 번에 하나만 받습니다. 이 북마클릿은 내 브라우저에서 태그를 하나씩 대신 쳐 넣습니다(로그인·발행은 건드리지 않습니다).

1. 처음 한 번 — 아래 버튼을 북마크바로 끌어다 놓으세요 (v2 · 예전에 만든 북마크는 지우고 다시)
📌 네이버 태그 자동입력
북마크바가 안 보이면 Ctrl+Shift+B. 끌어놓기가 안 되면 「주소 복사」 후 북마크를 새로 만들어 주소에 붙여 넣으세요.
2. 글마다
  1. 여기서 「전체 복사」
  2. 네이버 글쓰기 → 발행 창에서 태그 입력칸을 한 번 클릭
  3. 북마크바의 「📌 네이버 태그 자동입력」 클릭 → 뜨는 창에 Ctrl+V → 확인
태그가 하나씩 자동으로 들어갑니다(30개 약 10초). 네이버가 화면을 바꾸면 안 될 수 있는데, 그때는 「▶ 다음 태그 복사」로 하나씩 넣으세요.

📸 어느 사진 세트로 채울까요?

★ 표시는 기본 세트 — 일괄 생성에서 키워드에 맞는 세트가 없을 때 들어갑니다. 세트는 「📸 사진 세트」에서 관리합니다.

⚡ 일괄 생성 — 키워드만 넣으면 순서대로 초안을 만듭니다

한 글에 1~2분 걸립니다. 이 창을 열어 둔 채 기다리세요. 각 글은 글감 선택 → 본문·제목·태그 생성 → 사진 자리 채우기 → 의료광고법 검수 → 저장까지 자동으로 진행되고, 끝나면 왼쪽 목록에 초안으로 쌓입니다. 이미 쓴 글과 겹치는 글감은 피합니다.
